# Naming and Branding

The source code of Sanctum is licensed under GPL-3.0-or-later (see `LICENSE`).
However, the name **"Sanctum"** / **"Санктум"** and the visual identity
(icon, color palette, philosophy texts) represent the brand under which
this code is published.

The brand is **not currently registered** as a trademark in any
jurisdiction. There is no enforceable legal monopoly on the name.
We rely on community norms.

### Please do
- Fork the code, study it, modify it, redistribute it under GPL.
- Run your own private build for personal use under any name you like.
- Cite Sanctum in research, reviews, and educational materials.

### Please do NOT
- Publish modified builds on app stores (Google Play, RuStore, F-Droid,
  etc.) under the names "Sanctum", "Санктум", or close derivatives
  ("Sanctum Pro", "MySanctum", "Sanctum+", "Санктум 2", "Sanktum").
- Use the app icon or visual identity in your published forks.
- Imply that your fork is endorsed by or affiliated with the original
  Sanctum project.

If you publish a fork — please choose a distinct name. This keeps users
who search for "Sanctum" finding the original, audited version.
