# Sanctum 1.3.0

**Version:** 1.3.0 (versionCode 4)  
**Date:** 2026-05-31  
**GitHub Release:** [v1.3.0](https://github.com/ralf134565-collab/sanctum/releases/tag/v1.3.0)

## Где скачать

| Канал | Flavor | applicationId | APK |
|-------|--------|---------------|-----|
| **GitHub Releases** | `global` | `com.pocketreflect.app` | `app-global-release.apk` (прикреплён к релизу) |
| **RuStore** | `rustore` | `com.pocketreflect.app.rustore` | публикуется в магазине отдельно |

Это **два разных приложения** для Android: можно установить оба, данные между ними не синхронизируются.

## Что нового

- **Картина** — вкладка со сводкой отметок и закономерностей за 30/90 дней (локально, без оценок)
- **Вечерняя музыка** — 5 встроенных треков + до 5 своих (MP3/Ogg), плашка на «Сегодня», только пока приложение открыто
- **Свой стиль в чате** — настраиваемый тон ответов ИИ с неизменяемыми правилами Санктума
- Настройки «Вечерний ритуал» перестроены: блок «На вкладке «Сегодня»», переименование своих треков
- История: в шапке месяца — самый частый тег (вместо топ-3)
- «Философия и методология» дополнена описанием новых функций (RU/EN)
- Нижняя навигация: 5 вкладок, выровненные подписи

## Исправления и полировка

- Музыка не сбрасывается в начало при смене громкости; старт в паузе до нажатия Play
- Русская локаль: «Санктум» вместо «Sanctum» в пользовательских текстах
- Подсказка при импорте трека: инструментальная музыка без слов

## Сборка из исходников

```bash
./gradlew :app:assembleGlobalRelease    # GitHub / sideload (com.pocketreflect.app)
./gradlew :app:assembleRustoreRelease   # RuStore (com.pocketreflect.app.rustore)
```
